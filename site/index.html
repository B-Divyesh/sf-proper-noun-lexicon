Offline automation

Run the same workflow with pnl.

One Rust binary runs the same workflow on local files.

$ cargo install --path cli
$ pnl demo
$ pnl import names.csv -o team.json
$ pnl correct -l team.json -i raw.txt \
    -o corrected.txt -a audit.json
